# Changelog

All notable changes to AccreDiff are documented here.

## v1.0.0 - 2026-07-26

### Added
- Versioned release metadata for the GMD model-description paper.
- Expansion-module examples for gas-disk migration, EDACM-style collision outcomes, and Fe-Ni-S ternary differentiation.
- Sulfur-bearing differentiation module with Rose-Weston and Boujibar sulfur partitioning workflows.
- Reproducible quickstart, cosmochemistry, accretion, impact, differentiation, and outcome-analysis examples.

### Changed
- Publication version metadata is aligned with the manuscript title: AccreDiff v1.0.0.
- README installation, example, citation, and release guidance has been updated for archival release.

### Notes
- A citable Zenodo DOI should be minted from the GitHub release before GMD submission and then added to the manuscript code-availability section.

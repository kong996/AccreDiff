# Fe–Ni–S Metal–Silicate Differentiation Examples

This folder contains two example notebooks for applying the standalone Fe–Ni–S
metal–silicate differentiation module implemented in
`src/accrediff/differentiation_sulfur.py`. The examples separate initial
planetary differentiation from later collision-driven differentiation because
the two stages use different sulfur partitioning prescriptions and reservoir
bookkeeping.

## Notebooks

### `Initial_Differentiation_S8.ipynb` — Initial Differentiation with Rose–Weston S8

Calculates an initial metal–silicate differentiation event directly from a bulk
elemental composition. Setting `event_index=0` selects the Rose–Weston S8
initial sulfur-partitioning prescription.

**Key steps:**
- Define elemental masses in grams on a chosen reference basis
- Convert elemental masses to molar inventories with `ad.constants.Elements`
- Configure pressure, temperature, oxygen fugacity, and sulfur-model parameters
- Compute baseline Ni, Si, and O partition coefficients with
  `SulfurKDCalculator`
- Solve the coupled Fe–Ni–Si–O–S metal–silicate equilibrium
- Find the light-element oxygen inventory required by the target IW condition
- Verify mass conservation and nonlinear-solver convergence
- Plot the percentage of each element residing in the equilibrated core and
  mantle reservoirs

**Input:**
- Elemental masses on a chosen reference basis; these are not normalized
  weight percentages or a closed 100 g composition. Oxygen is inferred from
  the target IW condition and contributes to the final modeled mass.
- Pressure in GPa and temperature in K
- Target oxygen fugacity relative to IW
- `SulfurKDParams` and solver tolerances

**Main outputs in memory:**
- `result`: converged initial differentiation result
- `diagnostics`: solver, sulfur-model, and mass-balance diagnostics
- `phase_result`: metal and silicate molar inventories after equilibrium
- `element_distribution_percent`: core/mantle percentage of each element

**Main AccreDiff APIs used:**
- `ad.constants.Elements`
- `SulfurKDCalculator`
- `SulfurKDParams`
- `SulfurDifferentiationEventDriver.make_ol_solver`

### `Subsequent_Differentiation_S7.ipynb` — Later Differentiation with Boujibar S7

Constructs a later collision event from embryo compositions generated by
`examples/Accrection/A_Embryos_Composition.ipynb`. Setting `event_index=1`
selects the composition-dependent Boujibar S7 prescription for an event with
pre-existing metal and silicate reservoirs. The input table does not establish
that these reservoirs were previously computed with S8.

**Key steps:**
- Load target and impactor embryo compositions
- Convert normalized molar compositions into mass-consistent molar inventories
- Separate equilibrating material from locked target-core and mantle reservoirs
- Add an explicit delivered sulfur inventory because the source embryo table
  does not track sulfur
- Derive sulfur parameters from the equilibrating composition
- Solve the coupled equilibrium at the target oxygen partition coefficient;
  oxygen inventory is inherited from the supplied phase compositions
- Recombine the equilibrated subsystem with the locked reservoirs
- Audit whole-event elemental conservation, including oxygen, and total
  modeled mass conservation
- Plot final whole-product core/mantle element percentages

**Input:**
- `../../Accrection/Tables/note_02_early_composition.csv`
- Target and impactor identifiers
- Equilibrating target-mantle fraction
- Delivered sulfur fraction
- Pressure, temperature, and solver tolerances; this example does not impose
  an independent target IW

**Main outputs in memory:**
- `result_object` and `result`: converged equilibrium result for the interacting
  subsystem
- `final_collision_product`: recombined post-collision component inventories
- `audit`: elemental inventory closure table, including oxygen
- `mass_before`, `mass_after`, and `mass_relative_error`: total modeled mass
  closure in the same scaled mass units as the input embryo masses
- `element_distribution_percent`: final core/mantle percentage of each element

**Main AccreDiff APIs used:**
- `SulfurKDCalculator`
- `SulfurDifferentiationEventDriver.make_solver_factory`
- `ForwardKDOSolverSulfur.solve_x_for_KD_O` on the solver returned by the factory
- `sulfur_params_from_composition`

## Sulfur Module

`src/accrediff/differentiation_sulfur.py` is a standalone Fe–Ni–S extension
whose input and output structures follow the main differentiation workflow
without depending on its solver implementation.

The module provides:
- Baseline Ni, Si, and O partition coefficients through
  `SulfurKDCalculator`
- Fe–Ni–S metal activity coefficients based on the Ma (2001) interaction model
- Initial-event sulfur partitioning with the Rose–Weston S8 prescription
- Later-event sulfur partitioning with the composition-dependent Boujibar S7
  prescription
- Coupled Fe, Ni, Si, O, and S mass-balance solution through
  `ForwardKDOSolverSulfur` and `SulfurOLSolver`
- Event-level solver construction and IW matching through
  `SulfurDifferentiationEventDriver`

Public compositions and sulfur distribution coefficients use a molar basis.
Where an empirical sulfur relation is defined on a mass basis, conversion is
performed internally before returning the corresponding molar distribution
coefficient.

## Scientific Scope and Current Assumptions

- Fe–Ni–S activities use true ternary normalization; dissolved Si and O are not
  included in the ternary activity fractions.
- Ma (2001) interaction parameters are used at their reference temperature
  without temperature scaling.
- The silicate FeO activity coefficient is currently fixed at `1.7`.
- The oxygen partition coefficient does not currently include a sulfur
  composition correction.
- The sulfide-capacity expression currently omits the TiO2, Na2O, and K2O
  terms.
- The same Si and O parameterization is extrapolated to low pressure; a
  separate low-pressure parameter set is not applied.
- Published calibration ranges are documented by the implementation but are not
  enforced. The solver accepts `P >= 0` and `T > 0`, so extrapolated results
  require independent physical review.

## Workflow Note

Use the S8 notebook for the first differentiation of a bulk body and the S7
notebook for a later event with pre-existing core and mantle reservoirs. In a
collision calculation, define explicitly which material re-equilibrates and
which reservoirs remain locked. Re-equilibrating an entire pre-existing planet
would erase its differentiation history and is only appropriate when that is
the intended physical scenario.

The embryo-composition table used by the later-event notebook contains no
historical sulfur inventory. Therefore, its sulfur result represents only the
explicitly supplied delivered sulfur unless an upstream sulfur-bearing
composition model is provided.

Added sulfur increases the modeled inventory mass. The S7 example retains the
original sulfur-free sum of embryo masses as `event_mass` for its illustrative
pressure prescription. Its conservation audit includes the added sulfur on
both sides of the calculation.

### Core Boujibar formula corrections

- Corrected the direct FeO term to use weight percent:
  `log10(w_feo) + 2.0`, where `w_feo` remains a mass fraction. Metal composition
  terms continue to use mass fractions.
- Corrected the sulfide-capacity oxide denominator to count `p.m / 2` Al2O3
  formula units because the solver stores `p.m` as AlO1.5 molar units.
- Preserved public function signatures, parameter meanings, result fields,
  event-model selection, whole-phase molar sums, and phase-mass definitions.
  Callers must not apply another factor of 100 or halve the stored AlO1.5
  inventory themselves.
- At fixed input composition, the FeO unit correction increases D_S by a factor
  of 100; the oxide-denominator correction has an additional composition-dependent
  effect. Final coupled phase inventories do not simply scale by 100.

# Fig. 2 第二阶段：木星、土星与扫掠共振开发方案

## 状态、目标与范围

本文是第二阶段的开发设计与实施记录。沿用 `FIG2_DEVELOPMENT_PLAN.md` 的目录约束：新模块、实验脚本和测试先放在 `examples/Expansion_module/GasDrag_Type1/`；不修改 `src/accrediff/`。审核代码、物理假设和数值结果后，再单独评估迁入核心目录。

目标是从已完成的 `PaperFig2Disk`、`GasFlowPolicy` 与 `AerodynamicDrag.acceleration` 出发，增加太阳、木星、土星和四颗无质量 10 km 测试粒子的直接轨道积分，再加入随气盘消散改变的轴对称盘引力。最终输出与论文 Fig. 2 对应的 `a(t)`、`q(t)=a(1-e)`、`Q(t)=a(1+e)`，并叠加 `ν5`、`ν6` 和木星平均运动共振的位置。**共振必须由动力学力产生；绘在图上的共振位置只是诊断，不能代替力。**

论文来源：Zheng、Lin 与 Kouwenhoven (2016, arXiv:1610.09670v1)，§3.1–3.2、式 (1)–(6)、§4.1、Fig. 2。扫描世俗共振的经典背景见 Ward (1981)；本方案的积分器接口依据 REBOUND/REBOUNDx 的官方额外力文档。文献链接见文末。

## 论文模型的固定条件与未知量

默认时间范围 `0–10 T_dep`，`T_dep=1 Myr`；绘图为约 `0.1–10 T_dep` 的对数横轴。四颗粒子的初始半长轴为 `3.5、3.2、2.7、2.3 AU`，物理半径为 `10 km`；它们对太阳和巨行星的引力可忽略。行星使用太阳、现今质量的木星和土星；论文默认 `a_J=5.2 AU`、`a_S=9.58 AU`、`e_J=0.05`、土星初始近圆，系统共面。盘引力采用木星附近间隙的内外边界 `R_in=4.5 AU`、`R_out=11 AU`；全局盘密度随 `exp(-t/T_dep)` 消散。

论文正文没有充分固定 Fig. 2 四条轨迹的所有初始平均近点角、近心点经度、历元和数值输出采样。MMR 附近的尖峰对这些相位敏感。开发时所有初始角度和随机种子须记录在配置与输出元数据中；“复现动力学机制与统计形态”和“逐像素重现单次轨迹”分开验收，不用未说明的相位调参来制造外观吻合。

## 动力学方程与力的所有权

以太阳、木星、土星、四颗测试粒子的瞬时位置与速度为状态。基础引力由 N-body 后端计算，测试粒子质量设为零，不反作用于巨行星。额外力分两类：

```text
对巨行星：a_total = a_Nbody + a_disk_gravity
对测试粒子：a_total = a_Nbody + a_disk_gravity + a_aerodynamic_drag
```

太阳作为盘势的中心；在后端使用质心坐标时，计算盘力要先转成相对太阳的位置，保持惯性坐标与单位一致。木星、土星不受 10 km 天体阻力模型作用。气盘引力的表面密度因子在固定空间位置应随 `exp(-t/T_dep)` 缩放；若引入间隙演化，须另列模型，默认保持论文固定间隙几何。

建议统一外层单位为 `AU`、`M_sun` 和 GENGA-like code time (`G=1`、`1 code time=1/(2π) yr`)。N-body 后端、盘引力和既有阻力 `acceleration` 在内部均接收这一单位体系。绘图及配置层才做 `Myr` 转换；每次额外力回调将后端时间明确转换为 `t_myr`。配置和输出同时保存单位体系版本，禁止把 Myr 数值直接传给积分器的 code-time 时钟。

## 带间隙气盘引力

论文式 (3) 描述位于间隙内的巨行星所受盘力，式 (4) 描述内盘测试粒子的盘力。第一步以这两式为**保真目标**，梳理式中级数系数、截断条件及径向适用范围；不要把目前 `gas_migration.py` 的迁移扭矩或 `gas.cu` 中的气体阻力误作盘引力。若先采用数值环积分验证，必须显式给出盘内、外边界、`4.5–11 AU` 空隙、有限厚度或软化选择，并检查其对进动率的影响。论文薄盘公式和数值软化模型不能默认等价。

建议分两层实现：

1. **参考层：**高精度但较慢的盘势或径向力计算，在固定 `r,t` 上与论文式 (3)–(4) 的适用区域比对；检查力的方向和指数消散比例。
2. **积分层：**把已验证的径向力制成一维表并插值，每次回调只查表、乘时间衰减因子，再转为笛卡尔加速度。表的导数连续性和插值误差也应验证，因为进动率对力的径向导数敏感。

内盘测试粒子和间隙中巨行星可以使用不同的论文分支，但对外保持统一 `acceleration` 接口。轨道越过 `R_in`、穿入间隙或发生近距离散射时，应记录进入适用域事件，并切换到明确的通用数值力或停止该段的论文公式外推；不能静默沿用错误分支。盘质量在远端的截断半径要做敏感性测试，不能用无限外盘的未收敛数值积分。

## N-body 后端与计算成本

第一版建议使用**REBOUND 作为实验后端**，在短时间窗口用 `IAS15` 与 `additional_forces` 检查轨道和速度依赖力；官方文档要求对阻力设置速度依赖标记。长达 10 Myr 的四条直接轨道需性能评估，再选编译的额外力回调、合适的长期积分器，或已有的 GENGA 工作流。对于约 2 AU 的粒子，轨道周期只有数年，若每轨道约 20–40 步，10 Myr 可能需要约 `10^8` 次积分步；每一步调用 Python 力回调不适合作为正式运行路径。REBOUND/REBOUNDx 文档也明确提示 Python 回调比 C 实现慢。

不能仅因为某个积分器运行更快就直接使用：时间依赖的盘势和速度依赖的阻力破坏纯保守辛结构。若采用 `WHFast` 加额外力，须通过与短段高精度 `IAS15` 解的收敛比对决定时间步、力拆分与输出采样。盘力插值和气体阻力的误差要分别测量。长运行应支持断点、配置哈希、版本及数值守恒/耗散诊断，并把轨道状态保存为可重绘的数据文件，而非仅保存图片。

## 世俗共振与 MMR 诊断

诊断模块求每个时刻的行星世俗模态频率 `g5(t)`、`g6(t)`，以及测试粒子在半径 `a` 的自由近心点进动率 `g_p(a,t)`。`ν5` 与 `ν6` 的位置分别由 `g_p(a,t)=g5(t)` 和 `g_p(a,t)=g6(t)` 的根给出。行星模态需跟踪频率**和特征向量的连续性**，不能按每一时刻两个特征值的大小重新命名，否则模态接近时可能交换标签。测试粒子的进动率包含行星世俗扰动和同一盘引力；根搜索允许零个或多个根，不能人为强制单值曲线。

可先用线性世俗理论和盘力的近圆轨道进动率生成解析诊断线，再从直接 N-body 输出的偏心率矢量时序做独立频率检查。线性理论在 MMR 附近失效，因此诊断线上应标记或屏蔽这些区域，不能拿共振根代替直接轨道激发。木星内侧 `p:q` MMR 的绘图位置由固定行星半长轴的周期比给出，先标 `2:1、7:3、5:2、3:1、4:1`；若行星轨道有可测漂移，应按其即时 `a_J(t)` 更新而非固定水平线。

## 数据产品与作图

每次运行至少保存：配置与代码版本、种子及全部初始轨道角、后端与时间步、力开关、盘势表版本、`t`、所有粒子的笛卡尔状态、相对太阳的密切轨道根数 `a,e,ϖ`、近日点 `q`、远日点 `Q`、停机/碰撞/越界事件。输出图用论文的对数 `t/T_dep` 横轴，从正时间样本开始；在同一坐标上绘四组 `q,a,Q`、`ν5/ν6`、MMR。图注必须写明模型版本及未重现的论文条件。

近轨道尺度的 `q/Q` 振荡和窄 MMR 尖峰需要足够密的采样；只在对数等间距时间点取样可能漏掉尖峰。原始状态可按适当固定/自适应节奏记录，再对出版图生成抽样曲线，同时保留每个输出区间的 `a,e,q,Q` 极值。约 10 Myr 的全量高频轨迹数据量需预先估算和分块存储。

## 开发阶段与验收门槛

| 阶段 | 产物 | 必须通过的核对 |
| --- | --- | --- |
| A. 无盘纯引力 | 太阳-木星-土星和四颗测试粒子短段轨迹 | 双体周期、无盘能量/角动量误差、MMR 标称半径；改变输出节奏不改变动力学 |
| B. 盘引力 | 论文间隙力与插值表 | 式 (3)–(4) 对照、径向连续性、时间 `e^-1` 缩放、表分辨率/边界收敛；行星与粒子都确实施加盘力 |
| C. 进动和扫掠 | `g5/g6/g_p` 与 `ν5/ν6` 曲线 | 关闭盘时接近无盘基准；有盘时根随消散移动；模态标签连续；排除 MMR 处的线性理论假解 |
| D. 阻力耦合 | 独立力开关和短段直接积分 | 仅阻力时与第一阶段轨道平均的长期趋势一致；仅盘势时无耗散；全力时在短段上与高精度解收敛 |
| E. 10 Myr 轨迹 | 四组 `q,a,Q` 与 Fig. 2 风格图 | 时间步、盘表、输出采样和初始相位敏感性；分离 MMR 与 SR 事件；各轨道变化可由动力学事件解释 |

最终对照应分三层报告：**物理条件是否同论文、共振扫掠与内移是否定性一致、数值轨迹与论文单次曲线是否定量一致**。论文未给全初始相位时，最后一层不得声称唯一复现。Type-I 不参与 10 km 图的生产运行；后续研究若需要两种机制比较，应另建实验，不向 Fig. 2 的阻力力中叠加 Type-I。

## 实施记录与未通过的门槛

已在本目录实现 `paper_fig2_gravity.py`、`paper_fig2_system.py`、`paper_fig2_integrator.py`、`paper_fig2_compiled.py`、`paper_fig2_force.c`、`paper_fig2_resonances.py`、`paper_fig2_diagnostics.py` 和 `run_paper_fig2_resonances.ipynb`。数值盘势来自带 `4.5–11 AU` 间隙、有限外边界和可调软化的环积分；通过样条提供径向力及导数。直接积分使用 REBOUND 4.4.8，测试粒子质量为零，所有初始轨道根数相对太阳定义。阻力、盘引力和行星引力可独立关闭。近圆轨道进动率与线性世俗矩阵生成候选 `ν5/ν6` 根。编译的 C 额外力回调提供论文专用气盘的长期实验路径；通用盘适配器仍可走 Python 路径。

目前的验证：目录内测试覆盖开普勒基准、阻力开关、无质量粒子的行星轨道不变性、盘势梯度、指数消散、MMR 半径、扫掠根、编译与 Python 力的一致性，以及轨迹保存和重载。默认软化环模型中，`ν5` 候选根约从 `t=1 Myr` 的 `4.18 AU` 移至 `t=2 Myr` 的 `3.25 AU`、`t=5 Myr` 的 `1.99 AU`。这说明**当前近似模型**确实产生了向内扫掠，不是对论文薄盘公式的定量验证。短段 `100 yr` 实测中，Python 力回调下 IAS15 约 `8 s`，WHFast `dt=0.025 yr` 约 `1.4 s`，而 `dt=0.1 yr` 在偏心率上明显偏离 IAS15。同条件的编译力与 Python 力轨迹在 `100 yr` 后半长轴差小于 `2×10⁻¹³ AU`、偏心率差小于 `5×10⁻¹⁴`；`0.1 Myr` 编译路径已跑通。

以下门槛仍未通过，因此不得把当前图称为论文 Fig. 2 的定量复现：

1. **盘引力保真：**当前软化环势尚未与论文式 (3)–(4) 的 Ward 薄盘级数逐点核对；软化长度、内外边界和间隙边界对进动率与扫掠位置的影响还需系统测试。
2. **长期后端：**编译额外力回调已实现，但 10 Myr 的生产运行仍缺少断点恢复、长时步长收敛和近距离遭遇处理。notebook 默认只跑 500 yr 短段实验；完整运行由显式开关启用。
3. **长期收敛与数据：**尚未完成 10 Myr 的时间步收敛、MMR 事件密集采样、碰撞/散射处理和与论文 Fig. 2 的定量轨迹对照。
4. **初始相位：**论文未完整提供四颗粒子的轨道角。当前零角设置为明确记录的实验假设，不能视为论文唯一初始条件。

### 探索性 10 Myr 运行（2026-09-18）

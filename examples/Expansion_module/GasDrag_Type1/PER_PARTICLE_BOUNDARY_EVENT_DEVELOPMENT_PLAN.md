# 多测试粒子边界事件与独立终止：开发方案

## 目标与适用条件

同一次太阳—木星—土星积分中允许放置多个不同初始位置的测试粒子。当某一测试粒子离开规定的研究区域时，记录该粒子的首次事件并只终止该粒子的有效轨迹；其余测试粒子和巨行星继续积分。结果保持固定的初始粒子编号和输出数组形状，便于比较不同初始位置。

这套局部终止只适用于 `m=0`、不反作用于恒星和行星的测试粒子。当前 `integrate_fig2` 正是这种设置，测试粒子之间也不相互作用。若以后加入有质量胚胎，任一对象的移除都会改变其他对象的动力学，不能沿用本方案而不重新定义物理模型。木星、土星或其他有质量对象出现越界、非有限状态或力表失效时，仍终止整个模拟。

所有实现继续放在 `examples/Expansion_module/GasDrag_Type1/`，不修改 `src/accrediff/`。本文只规定开发方案，本轮不修改计算代码。

## 分离数值力表和实验边界

现有 `GapGravityConfig.table_min_au/table_max_au` 是盘引力插值表的数值有效域，不是物理碰撞或逃逸条件。新增独立配置 `ParticleBoundaryConfig`：

```python
@dataclass(frozen=True)
class ParticleBoundaryConfig:
    inner_termination_au: float = 0.3
    outer_termination_au: float = 13.0
    event_check_interval_years: float = 100.0
    require_positive_energy_for_ejection: bool = True
```

第一版把越过内、外实验边界视为吸收事件，不允许粒子重新进入后恢复有效轨迹。事件类型区分为：

- `inner_domain_exit`：`r <= inner_termination_au`；
- `outer_domain_exit_bound`：`r >= outer_termination_au`，但太阳二体诊断能量仍为负；
- `ejected`：向外运动、太阳二体诊断能量非负，并越过外边界；
- `nonfinite`：粒子位置或速度出现非有限值；
- 后续可扩展 `stellar_collision`、`planet_collision`、`close_encounter`，但不在第一版用未经定义的半径自动判定。

“太阳二体能量”只用 `E=|v-v_sun|²/2-GM_sun/r`，是分类诊断，不包含行星与时变盘势，不能作为严格的多体守恒量。事件同时保存径向速度；`ejected` 要求 `v_r>0`，避免把瞬时正能量或向内穿越误标为外逃。

力表须覆盖实验边界并留出缓冲。例如研究边界为 0.3–13 AU 时，建议盘力表至少覆盖 0.1–50 AU，并按原表间距增加 `n_table`。构造时强制校验：

```text
table_min < inner_termination < outer_termination < table_max
```

若禁用某一实验边界，则仍需保证所有活跃有质量对象处于力表内。盘的环积分外边界与力表上限是不同概念：盘可截断在 50 AU，而截断盘在其外部仍有引力；是否将力表延伸到外盘之外必须显式配置并做插值收敛检查。

## 事件检测与粒子生命周期

### 活跃状态

每个初始测试粒子拥有稳定的逻辑编号、名称和状态：

```text
ACTIVE -> EVENT_RECORDED -> REMOVED
```

事件只允许首次写入，后续不得覆盖。C 和 Python 力回调首先检查活跃粒子的瞬时日心位置与速度。达到实验边界时：

1. 在该次力求值时记录准确的首次事件时刻和状态；
2. 立即将该粒子在额外力层标为不活跃，不再计算盘引力和气体阻力；
3. 不抛出全局异常，其他粒子继续接受完整额外力；
4. 在下一个内部事件检查点把事件复制到 Python，并从 REBOUND 中移除该零质量粒子；
5. 重建编译回调的当前粒子映射，然后继续积分。

不能直接在 `additional_forces` 回调内删除 REBOUND 粒子，因为循环中的粒子数组和索引可能失效。事件发生到内部检查点之间，失效粒子仍受 REBOUND 的恒星/行星引力，但不受额外力；由于其质量为零，它不会影响其他粒子。检查间隔应足够短，避免失效粒子在移除前形成非有限状态。

积分器不能只依赖用户的稀疏输出时刻检查事件。10 Myr 对数采样的相邻输出在晚期可能相隔很长。实现时把每个用户输出区间再分为不超过 `event_check_interval_years` 的内部段；内部段只做事件收集和移除，不写入常规轨迹。C 回调记录的事件时刻来自实际力求值，因此事件时间精度主要由积分步长决定，而非输出或检查间隔。

### 稳定身份和移除顺序

对外使用初始稳定名称 `particle_0`、`particle_1` 等，不用可变化的 REBOUND 数组位置作为长期身份。移除时按当前 REBOUND 索引从大到小执行，避免同一批事件导致索引移位。之后通过 particle hash 重建“当前 REBOUND 索引 ↔ 初始输出列”的映射，并重新绑定编译回调。绘图、保存和事件表始终使用初始名称。

## C 编译回调设计

Python bridge 为当前模拟分配并持有以下连续数组，把指针传给 C；不得使用固定最大粒子数：

```text
active[N]
event_code[N]
event_time_code[N]
event_r[N]
event_position[N,3]
event_velocity[N,3]
event_radial_velocity[N]
event_kepler_energy[N]
```

C 回调只允许为 `j >= first_test` 的零质量测试粒子触发局部事件。有质量对象超出盘力表、非有限或无法插值时，写入单独的 fatal 状态；Python 检查到 fatal 状态后仍抛出全局异常。测试粒子的实验边界位于力表内部，因此正常情况下会先触发局部事件，不应到达插值表错误。

局部事件发生后，C 在同一次及后续回调中跳过该粒子的盘引力和阻力。每次 Python 移除粒子后，新建 `CompiledFig2Force`，确保进程全局参数、数组长度、`first_test` 和当前索引一致。当前编译回调本来就不支持同一进程并行使用不同配置；本次不扩大并发能力。

## Python 后端一致行为

Python `additional_forces` 维护同样的 active 状态和首次事件记录，在调用 `gravity.acceleration` 之前检查实验边界，避免先触发 `_checked_radius`。内部事件检查点使用同一移除及输出映射逻辑。Python 与 C 后端必须使用同一公共事件代码、边界比较规则、二体能量和径向速度公式，不能各自复制不同判据。

建议新增 `paper_fig2_events.py`，集中定义：

- `ParticleBoundaryConfig`；
- `ParticleEvent` 数据类与事件代码；
- 状态分类和单位约定；
- 事件序列化/反序列化；
- 绘图标签。

`paper_fig2_system.py` 继续描述初始天体系统；边界策略通过 `integrate_fig2(..., boundaries=...)` 显式传入，不隐藏在行星或盘参数中。

## 输出数据结构

扩展 `Fig2Run`：

```python
active: np.ndarray       # shape=(n_times, n_names), bool
events: tuple[ParticleEvent, ...]
```

常规输出仍按初始 `names` 保持固定列。事件发生后：

- `active=False`；
- `position_au`、`velocity_code`、`a_au`、`e`、`omega_rad`、`q_au`、`Q_au` 写为 `NaN`；
- 事件瞬间的有限位置、速度和轨道诊断只保存在 `events`；
- 图线在最后一个有效样本结束，不连接到零值或后续无意义轨道；
- 事件位置用与事件类型对应的标记显示，并可选择在图例列出终止时间。

`.npz` 增加 `active` 和结构化事件字段或 `events_json`。事件数量通常很少，第一版可用 JSON，但必须保存全精度数值和 schema 版本。加载旧文件时若缺少新字段，应兼容为“全部有限样本 active、事件为空”，同时在 metadata 标明旧 schema；不能根据 NaN 猜测事件类型。

元数据新增边界配置、事件检查间隔、事件 schema 版本和终止统计。配置哈希必须包含这些字段，使旧结果不能冒充采用新边界策略的运行。

## notebook 使用方式

配置单元显式写出：

```python
boundaries = ParticleBoundaryConfig(
    inner_termination_au=0.3,
    outer_termination_au=13.0,
    event_check_interval_years=100.0,
)

gap_cfg = GapGravityConfig(
    table_min_au=0.1,
    table_max_au=50.0,
    n_table=3072,
    ...,
)
```

长积分完成后打印每颗测试粒子的状态：存活、内边界退出、受束缚外域退出或逃逸，以及事件时间和半径。一次运行即使部分粒子终止，也正常返回并保存其余轨迹。只有 fatal 行星/力表错误、配置错误或积分器失败才使整个 cell 抛异常。

## 验收测试

1. **配置校验：**实验边界严格位于盘力表内部；检查间隔为有限正值；无效或颠倒边界在积分前报错。
2. **单粒子局部终止：**构造一颗快速越界粒子和一颗稳定粒子。前者仅产生一次事件，后续输出为 NaN；后者完整积分。
3. **不影响其余粒子：**把“稳定粒子 + 会越界粒子”的结果与只运行稳定粒子的对照比较。行星及稳定粒子的 `position, velocity, a, e` 应在舍入误差范围内一致。这是核心验收门槛。
4. **多粒子同段事件：**两个测试粒子在同一内部检查段越界，事件均保存，按倒序移除后剩余名称映射正确。
5. **有质量对象 fatal：**木星或土星越出力表仍全局失败，异常包含对象、时间、半径和有效域。
6. **Python/C 对照：**同一短段实验的事件对象、类型和时刻在积分步长容差内一致；未终止粒子的轨迹达到现有力回调一致性标准。
7. **输出往返：**保存/读取后 active mask、事件字段和 NaN 区域完全一致；旧 `.npz` 可加载但明确标为旧 schema。
8. **绘图：**终止后不连线，事件标记位于记录的时间/半径；全部粒子存活和部分终止两类图均正常。
9. **性能：**比较不同 `event_check_interval_years` 的运行耗时；确认内部检查不会使 10 Myr 编译路径出现不可接受的 Python 调用开销。

## 当前自定义实验的处理决定

对于已诊断的 `Sigma0_cgs=2000`、100 km、`rho_p=3 g/cm³` 实验，三个步长都由 `particle_0` 向外强散射。若实验边界保持 13 AU，新机制将在首次穿越时记录 `outer_domain_exit_bound` 并终止该粒子的有效轨迹，同时继续计算其他三颗测试粒子。独立的 50 AU 扩表诊断显示该粒子随后成为非束缚轨道，这支持“强散射后离开内盘样本”的解释，但 13 AU 终止运行本身不能再记录后续 50 AU 的 `ejected` 事件。若研究目标改为逃逸过程，应把外终止边界显式设为 50 AU 或更远，并使用相应宽度的力表与近距离遭遇积分方案；不应只为获得一条表面连续的 10 Myr 内盘曲线而不断扩大力表。

开发完成后，仍需对事件时间的步长敏感性单独报告。局部终止能避免一颗粒子中断整个批量实验，但不会使混沌散射时间自动成为收敛的定量预测。

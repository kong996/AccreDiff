## 组成口径

A_01 保留 MgO 归一化展示表，另外输出每 100 g 完整端元的摩尔库存和未建模质量覆盖表。B_01 使用 N-body 来源质量比例直接混合库存，不将端元归一化到单位总摩尔数。D_01 单独传递未建模质量；E_01 保留 CMF 字段作为已建模组分的条件 CMF，另给出质量覆盖率及完整物体 CMF 上下界。

批处理参数快照以 `composition_basis=mol_per_100g_whole_body` 标记新口径。新增表格与字段意味着旧 Tables 不能直接从 B/D/E 接着计算；新计算应从 A_01 开始。旧 runs、results 和 notebook 保存输出保持原样，本次未重算或迁移历史产物。
